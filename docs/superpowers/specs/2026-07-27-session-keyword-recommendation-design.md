# 투표 세션 키워드 추천 반영 설계

## 목표

방장이 투표 시작 전에 입력한 `likeKeyword`와 `dislikeKeyword`를 OpenAI 메뉴 큐레이션에 실제로 전달하고, 일반 회원 취향보다 우선하는 당일 추천 방향으로 사용한다.

## 설계

추천 생성 시 이미 조회한 `VoteSession`에서 두 키워드를 읽는다. 기존 선호·비선호 신호 목록의 첫 항목에 각각 `오늘의 핵심 선호:`, `오늘의 핵심 비선호:` 접두어를 붙여 전달한다. OpenAI 시스템 프롬프트는 이 접두어가 붙은 신호를 일반 회원 취향보다 우선하도록 지시한다.

결정론 점수 기반 30개 후보 풀, 알레르기 하드 제외, 기존 회원별 온보딩 취향, AI 실패 시 상위 후보 대체 동작은 유지한다.

## 검증

서비스 단위 테스트에서 세션 키워드가 큐레이션 서비스까지 전달되는지 확인한다. OpenAI 어댑터 테스트에서 생성 프롬프트가 두 핵심 키워드를 포함하고 우선순위를 명시하는지 확인한다.
